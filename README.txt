BADR LIFT V6 - WHAT CHANGED

Original inaccurate schematic movement animations have been removed.
Curated exercise-specific technique videos are embedded via official YouTube players for the matched exercises. The videos are streamed from their original creators and require Internet access. Source embedding may be unavailable in some restricted viewers; use Open source to open in YouTube.
Unmatched exercises show no generic substitute. In each exercise, use Add video to supply an exact YouTube URL or direct HTTPS MP4/WebM URL; custom links save in app backups.
Install by extracting this ZIP to your existing HTTPS site (overwrite index.html, manifest, sw.js, icons). Keep the original site URL to retain localStorage data. Export a JSON workout backup before updating.
Existing 4-day program, logs, measurements and recovery screen remain in place. Apple Health synchronization requires the separate native iPhone bridge; this web file does not read HealthKit directly.
